01

What we built

A single web page — no app store, no install, no account — that reads your Sleeper league directly and turns it into four views.

  • OverviewRecord, points for/against, league rank, waiver budget, current NFL week.
  • My TeamYour starters and bench in your league's exact lineup slots, with live injury flags.
  • StandingsThe full league table, your row highlighted.
  • Waiver TargetsTrending adds league-wide, filtered to free agents, ranked against your roster's actual gaps.
  • StrategyRule-based notes: injured starters, thin positions, schedule-luck read, trade angles.
02

How data flows today

Two separate jobs are happening, and it matters that they're separate: one place hands you the app, a different place hands you the data — and nothing of mine sits in between.

That's the whole trick behind "live": the page doesn't store a snapshot of your league anywhere. It re-asks Sleeper the same questions every time it opens, and again every five minutes after that, so it's always looking at the current state of your league.

04

Security posture

The short version: there's nothing secret in this app, because nothing secret was ever needed.

  • ✓No credentials anywhere. No password, login, or API key is stored in the code — Sleeper's public data doesn't require one.
  • ✓Read-only, always. The app can only look at league data. It can't submit a waiver claim, make a trade, or touch your real Sleeper account.
  • ✓Nothing leaves your device. The only saved state — your league ID and which team is yours — lives in your browser's local storage, never sent anywhere.
  • ✓No middleman server. Data goes browser ↔ Sleeper directly. There's no server of ours collecting, logging, or relaying what you look at.
  • ✓Safe to make public. The GitHub repo could be fully open-source with zero risk, since making the code visible reveals no secret — it's the same logic anyone could already write against Sleeper's open API.
05

Next steps

Two different directions from here — you don't need AI to keep improving this, but here's what each path costs.

Keep iterating — no AI needed

More rules, more data

  • Pull season stats to project points instead of just counting rostered bodies
  • Support more than one league from the same page
  • Add a trade value calculator between two specific players
  • Push a browser/phone notification when a starter's status changes
  • "Add to Home Screen" so it opens like a native app
Add real AI

A model, not just rules

  • Natural-language weekly recap: "why you won/lost," in plain sentences
  • Judgment calls the fixed rules can't make — trade fairness, start/sit reasoning
  • Answers to open questions you type in, not just fixed checks
  • Costs money per request, and needs a place to keep the API key secret
Why not just call the AI from app.js directly? Any key pasted into browser-side JavaScript is readable by every visitor — right-click, "view source," done. That's fine for Sleeper's key-free public data, but an AI provider's key is billed to whoever holds it, so it has to live somewhere a visitor's browser can't reach: a small backend function (a free tier on something like Cloudflare Workers or a Vercel function) that takes the request, adds the secret key itself, calls the AI, and hands back only the answer.
